🐙 Panduan Push ke Akun GitHub Lain (ParamaraStudio)

Agar push repository ini tidak bentrok dengan akun GitHub utama Anda di Mac, jalankan perintah lokal di bawah ini.

1. Konfigurasi Git Lokal yang Sudah Aktif di Repo Ini:

git config --local user.name "paramarastudio" git config --local user.email "paramarastudio@gmail.com"

2. Cara Push via Personal Access Token (HTTPS):

git add . git commit -m "feat: initial commit Shopee Live AI Tracker" git branch -M main git remote add origin https://github.com/paramarastudio/shopee-live-ai-tracker.git git push -u origin main

Saat diminta password di Terminal, masukkan Personal Access Token (PAT) dari akun GitHub paramarastudio.

3. Verifikasi Konfigurasi Lokal Saat Ini:

git config --local -l
